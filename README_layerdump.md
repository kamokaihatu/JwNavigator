# Jw_cad レイヤ状態ダンプ — 確定版

全レイヤグループ×全レイヤ（16×16＝256）の状態を、外部変形1回で取得します。
`LD_F.bat` で `group=16 / layer=256` を確認済み。

出典は Jw_cad 同梱の `C:\jww\JWW_SMPL.BAT`（作者による外部変形の仕様書）です。

---

## 使い方

`LAYERDUMP.bat` と `dump_layers.py` を同じフォルダに置き、
Jw_cad の「その他」→「外部変形」→ `LAYERDUMP.bat`。

範囲選択を求められるので、**線が数本入る程度の小さい範囲**を選んで【選択確定】。
図面全体を選ぶ必要はありません（全体を選ぶと巨大なデータが書き出されて重くなります）。

Jw_cad の画面に結果が出ます。

```
[DUMP] group=16 layer=256 write=lgf/ly0
```

出力は `layerdump\` に。**`matrix_*.csv` が16×16の一覧表**で、これが一番見やすいはずです。

---

## バッチの制御行（ここが要点）

```
REM #jww
REM #h1     ← データ選択方式。これが無いと #g1 が効かない
REM #g1     ← 必ず #h* の直後。全レイヤグループ選択
REM #gn     ← レイヤの状態と名前を書き出す。これが無いと何も出ない
REM #e
```

仕様書の該当箇所：

```
◎レイヤグループ・レイヤ状態、レイヤグループ名・レイヤ名の書込み
        #gn
◎データ選択のときレイヤグループのデータ選択指定
 （必ず「#h*」または「#hc」の後に続けて記載する）
        #g0 (or無指定):書込レイヤグループのみ選択
        #g1 全レイヤグループ選択
◎データ範囲選択指定
        #h0:データ選択をしない、データ書き出し無し
        #h1:範囲内のデータのみを選択
```

さらに、**`REM #jww` が無い bat は外部変形の一覧に表示されません。**

### 検証の記録

| 制御行 | 結果 |
|---|---|
| `#gn` `#g1`（元の LDUMP） | group=1 layer=16 … `#g1` が `#h*` の後に無いので無効 |
| `#h0` `#g1` | group=0 layer=0 … `#gn` が無い |
| `#h4` `#g1` | group=0 layer=0 … 同上 |
| `#g1` のみ | group=0 layer=0 … 同上 |
| `#h1` `#g1` | group=0 layer=0 … 同上 |
| **`#h1` `#g1` `#gn`** | **group=16 layer=256** ✅ |

## 状態値の意味（仕様書の定義・確定）

`ly%x %d` の `%d` は2桁。

| 値 | 意味 |
|---|---|
| `11` | 編集可能、表示状態 |
| `01` | 編集不可、表示状態（＝表示のみ） |
| `00` | 編集不可、非表示状態（＝非表示） |

10の位が2以上はプロテクト。

| 10の位 | 意味 |
|---|---|
| 2 | 編集不可でプロテクト（表示・編集状態の変更可能） |
| 3 | 編集可能でプロテクト（表示・編集状態の変更可能） |
| 6 | 編集不可でプロテクト（変更不可） |
| 7 | 編集可能でプロテクト（変更不可） |

`lg%x %d`（レイヤグループ状態）も同じ形式です。

**書込レイヤ**は状態値ではなく、ヘッダ部の**値なし** `lgf` / `ly0` で示されます。
スクリプトはこれを拾って `write=lgf/ly0` と表示し、CSV の「書込」列に○を付けます。

つまり調べようとしていた4状態は、こう対応します。

- 非表示 → `00`
- 表示のみ → `01`
- 編集可能 → `11`
- 書込 → ヘッダの値なし `lg*` / `ly*`

## 復元は「レイヤ設定ファイル(.JWL)」で行う

外部変形では状態を書き戻せません（実機で確認済み。`ly2 00` を返しても
書込レイヤが動くだけで状態は変わらなかった）。

代わりに Jw_cad には**レイヤ設定ファイル (.JWL)** があり、
全レイヤグループ・全レイヤの状態をファイルで一括設定できます。

`A_SAVE.bat` は保存時に、この復元用ファイルを自動生成します。

- `C:\jww\LAYER_RESTORE.JWL` … 常に最新（復元はこれを読む）
- `layerdump\restore_*.jwl` … タイムスタンプ付きの控え

### 復元手順

Jw_cad の [設定] → [環境設定ファイル] → [読込み] →
ファイルの種類を `*.JWL` にして `LAYER_RESTORE.JWL` を選ぶ。

これで256レイヤの状態と書込レイヤが保存時に戻ります。

### JWL の値の意味（SAMPLE.JWL より）

```
LAYCND_0 =[G],(0),(1),...,(F)
```

先頭がレイヤグループ自身の状態、続く16個が各レイヤ。

| 値 | 意味 |
|---|---|
| 100以上 | 書込レイヤグループ／書込レイヤ |
| 1の位 0 | 非表示 |
| 1の位 1 | 表示のみ |
| 1の位 2 | 編集可能 |
| 10の位 1 | プロテクト（状態変更可） |
| 10の位 2 | プロテクト（状態変更不可） |

`PRTCT_CH = 1` を書くとプロテクト状態も変更できます（生成ファイルは 1）。

外部変形側（`#gn`）の値とは体系が違うので、スクリプトが変換しています。

| `#gn` | JWL |
|---|---|
| `11` 編集可能・表示 | `2` |
| `01` 編集不可・表示 | `1` |
| `00` 非表示 | `0` |

### 未確認

Jw_cad 10.03 で `.JWL` の読み込みが仕様どおり動くかは、まだ実機で確認していません。
`.JWL` の機能はバージョン2.20頃の追加で、以後の変更履歴には記載がありませんでした。
