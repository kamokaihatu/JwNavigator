# JwNavigator Ver3.51 取扱説明書

高解像度（4K等）モニター環境では、Jw_cad本体のツールバーが小さく、マウスで狙うのが負担になります。この負担を軽減するために開発された、Jw_cad専用のコマンドパレットです。

ユーザーの環境設定（jw_win.jwf）には手を加えないため、既存の設定に影響を与えずに導入できます。

---

## 1. おすすめの設置場所（超重要!!）

本アプリ一式（フォルダごと）をデスクトップ等で動かすと、Windowsの仕様で**OneDriveの自動同期がうるさく走り、動作が重くなったりファイルがロックされる原因**になります。

トラブルを完全に防ぐため、本アプリのフォルダは **`C:\jww\` フォルダの中（Jw_cad本体と同じ場所）に格納して動かすのが圧倒的におすすめ**です。
（例： `C:\jww\JwNavigator\` の中に`JwNavigator.exe`一式を並べる）

### 初回起動時に「WindowsによってPCが保護されました」と出た場合

署名付きの配布ではないため、ダウンロードして初めて実行する際にWindows SmartScreenの警告が出ることがあります。表示された画面の**「詳細情報」**をクリックすると**「実行」**ボタンが出るので、それを押せば起動できます。

社内のグループポリシーで「実行」ボタン自体が表示されない設定になっている場合は、ユーザー側の操作だけでは回避できないため、IT部門に許可(除外設定)を依頼してください。

## 2. 起動と基本操作

`JwNavigator.exe` をダブルクリックすると静かに起動し、画面には見えませんがタスクトレイ（画面右下の通知領域）にアイコンが常駐します。図面を開くと、その図面の左右にパレットが自動でくっつきます。

### パレットの「追従」と「自由配置」

パレット上部の `👣 追従` ボタンをクリックするか、パレット自体をドラッグして動かすと、`自由` 表示に切り替わります。

* **`👣 追従`（ピンク）**: Jw_cadのウィンドウに磁石のようにくっついて追いかけてくる状態。
* **`自由`（グレー）**: 好きな場所に固定できる状態。パレットを右クリックして「📌 終了時の配置を記憶する」にチェックを入れておくと、次回起動時も同じ場所に復元されます。

### タスクトレイアイコンからできること

トレイアイコンを右クリックすると、以下のメニューが出ます。

* **`⚙️ 編集`**: ボタンの追加・削除・並び替え・色/アイコン変更ができる設定画面を開きます（ダブルクリックでも同じ画面が開きます）。
* **`📌 終了時の配置を記憶する`**: 上述の「自由配置」の位置を、次回起動時にも復元するかのON/OFFです（トレイからも切り替えられます）。
* **`👁️ 隠したパレットを再表示`**: 後述の「このパレットだけを閉じる」で消したパレットを全部戻します。
* **`🔄 初期構成を選び直す`**: 初回起動時に選んだパレット構成の選択画面をもう一度呼び出し、今の配置を上書きします（「設定を色々いじって元に戻したい」時用。上書き前に確認が入ります）。
* **`❌ JwNaviシステムを終了する`**: 常駐監視も含めて完全に終了します。フォルダの移動・削除・上書きインストールをしたい時はここから終了してください。

パレット自体を右クリックしても、同じ設定/終了メニューに加えて「このパレットだけを閉じる」（そのJw_cadウィンドウ分だけ非表示にする）が出ます。

## 3. パレットの右クリックメニューを簡略化する

パレット右クリックメニューの項目を絞りたい場合は `⚙️ 編集` の「右クリック」タブから、項目ごとに表示ON/OFFを切り替えられます。`⚙️ 編集` 自体は誤って消せないよう常に表示されます。

タスクトレイアイコンの右クリックメニューはこの設定の影響を受けず、常に全項目が表示されます（管理者・開発側がいつでも全機能へアクセスできるようにするためです）。

## 4. グループボタンについて

似た仲間のコマンド（例：伸縮・面取・コーナー）をまとめて1個のボタンに収納できる「グループボタン」です。右下に小さい青い三角のバッジが付いているボタンがこれです。

* **使い方**: グループボタンを押すと、中身の一覧がポップアップで出ます。使いたいものをクリックするとそのコマンドが実行され、ポップアップは閉じます（外側クリックや`Esc`キーでも閉じます）。
* 中身のコマンドを選ぶと、グループボタン自体の見た目もそのコマンドの見た目に一時的に切り替わり、選択中は凹んで表示されます。別のコマンドに切り替えると、グループ自体の見た目に自動で戻ります。
* **作り方**: `⚙️ 編集` → 右側の「追加」ボタン → 一覧の先頭にある「➕ グループボタンを作る…」を選ぶ → 名前を入力（例：「作図系」）→ 保存。作ったグループを選ぶと詳細欄に「中身を編集…」ボタンが出るので、そこからコマンドの追加・削除・並び替え・アイコン/色の個別設定ができます。不要になったら詳細欄の「グループ解除」で、中身を個別ボタンへ展開して元に戻せます。
* グループの中身には、通常のコマンドだけでなく「モードボタン」も入れられます（コマンド・線属性・レイヤーを一括で切り替えるボタン。作成は中身編集画面の「追加」から同様に選べます）。

複数コマンドを自動で連続実行する「マクロ」ボタンも構想中ですが、今回はまだ収録していません（また今度）。

## 5. レイヤ保存ボタンについて

「電灯配線図」「配管図」のように、全レイヤグループ・全レイヤ（16×16＝256マス）の表示/非表示・編集可否の状態をまとめて記録し、あとからワンクリックで呼び戻せるボタンです。

* **作り方**: `⚙️ 編集` → 右側の「追加」ボタン → 一覧の「➕ レイヤ保存ボタンを作る…」を選ぶ → 名前を入力（例：「電灯配線図」）→ 保存。「〇〇を保存」「〇〇を復元」という2個のボタンがペアで作られます。
* **使い方**: 「〇〇を保存」を押すと、今のレイヤ状態を記録します（外部変形が動くため7〜10秒ほどかかり、処理中はボタンが凹んだ見た目になります）。「〇〇を復元」を押すと、記録した状態を即座に反映します。
* すでにある保存ボタンに、復元ボタンだけを追加で作ることもできます（「レイヤ保存ボタンを作る」で「いいえ」を選び、紐付け先の保存ボタンを選ぶ）。
* **⚠️ 保存の注意点**: 保存には「編集可能なレイヤが少なくとも1つあり、かつ何かしら選択できる図形がある」ことが必要です。真っ白な図面や、編集可能なレイヤが1つも無い状態で保存を押すと、20秒ほど待った末に失敗します（ボタンは自動で元の見た目に戻ります）。
* 復元すると書込レイヤ（今編集中のレイヤ）も保存時点のものに切り替わりますが、直後に元の書込レイヤへ自動で戻すようにしているため、作業中のレイヤが変わってしまうことはありません。
* この機能はJw_cadの環境設定ファイル（`Jw_win.jwf`）にキー割り付けを1行登録しておく必要があります（現状は開発機のみ設定済み）。他の環境に導入する場合は別途この設定が必要です。

## 6. アイコンを自分の好きな画像(PNG)にするルール

本アプリは、画像と内蔵プログラムの自動両対応（ハイブリッド）構造になっています。設定画面（`⚙️ 編集`）のアイコン選択で、サムネイル一覧から選ぶのが基本の使い方です。自作の画像を追加したい場合のルールは以下の通りです。

#### 【パターンA】 自作のPNG画像（イラスト）をボタンにしたい場合
* `png_icons/` フォルダの中に、正方形（44〜48px、透過対応）のPNG画像を好きなファイル名で置きます（例: `myicon.png`）。
* 保存すると、そのファイル名がそのままアイコン名として設定画面のアイコン選択サムネイル一覧に自動で追加されるので、あとは画面を見て選ぶだけです。名前を何かに合わせる必要はありません。
* 例外として、「このコマンドをパレットに新しく追加した瞬間、自動でこのアイコンを付けたい」場合だけ、`data/commands_master.csv`の該当行の`default_icon`列と同じファイル名にしておくと、追加時に手動で選ばなくても自動で付きます。

#### 【パターンB】 PythonのCanvas（数式描画コード）でアイコンを自作する場合
* `icons/` フォルダの中に、`draw(canvas, x, y)` 関数を持つPythonファイルを好きなファイル名で配置します（例: `myicon.py`）。
* こちらも同様にファイル名がそのままアイコン名になり、画面のサムネイル一覧から選べます。exe化されたバージョンでも自動的に同梱・認識されるので、追加のimport作業などは不要です。

#### 【パターンC】 画像もCanvasコードも用意しない場合（自動救済）
* 画像やコードを用意しなくても、システムが自動で救済します。ボタンの真ん中にコマンド名を太字で自動描画します。

## 7. config.jsonを直接編集したい人向け

パレットの設定は`config`フォルダの`config.json`というテキストファイルに保存されています。設定画面から作れない組み合わせを試したい時などは、メモ帳等で直接編集することもできます。

* 保存する時は文字コードを**UTF-8**にしてください（Windows 11の新しいメモ帳ならデフォルトで大丈夫です。古いメモ帳だとANSIになり日本語が壊れることがあります）。
* JSONの構文（カンマや括弧）を崩すと、その面（左右どちらか）のボタンが読み込めず空になります。ただしアプリ自体がクラッシュすることはありません（壊れていたら黙って空の状態にフォールバックする作りになっています）。
* **編集する時は`⚙️ 編集`の設定画面を閉じておいてください。** 開いたまま直接編集して、そのあと設定画面側で「保存」を押すと、直接編集した内容が上書きされて消えます。編集後はアプリを再起動するか、トレイ経由で設定画面を開き直すと反映されます。

## 8. 不具合報告・利用状況のログについて

* `JwNavigator_Log.txt`（exeと同じフォルダに自動生成）に、動作ログが記録されます。不具合が起きた時はこのファイルの中身をコピペして報告してもらえると原因調査が早いです（肥大化を防ぐため5MBを超えると自動的に前半を切り詰めます）。
* 「JwNavigatorを使っていない人にも、jw_cadの使用状況だけ調べてほしい」という場合は、同梱の `JwNavigator_UsageLogger.exe`（`dist/JwNavigator_UsageLogger/` フォルダ）を単体で配れます。起動して作業してもらい、Ctrl+Cで終了すると集計結果が出ます。座標やキーの内容などは一切記録しません。
