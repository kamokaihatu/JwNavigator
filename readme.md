# 🚀 JwNavigator Ver1.2 (β版完成形) 取扱説明書

高解像度（4K等）モニター環境において、「Jw_cad本体のツールバーが小さすぎてマウスで狙うのが致命的に疲れる（イラッとする）」という実務の不満を完璧にへし折るために開発された、Jw_cad専用のハイブリッド高速コマンドパレットです。

ユーザーの大切な環境設定（jw_win.jwf）には1ミリも指を触れないため、100%安全に導入でき、非力なパソコンでも空気のように軽く動きます。

---

## 📂 1. おすすめの設置場所（超重要!!）

本アプリ一式（フォルダごと）をデスクトップ等で動かすと、Windowsの仕様で**OneDriveの自動同期がうるさく走り、動作が重くなったりファイルがロックされる原因**になります。

トラブルを完全に防ぐため、本アプリのフォルダは **`C:\jww\` フォルダの中（Jw_cad本体と同じ場所）に格納して動かすのが圧倒的におすすめ**です。
（例： `C:\jww\JwNavigator\` の中にファイルを並べる）

---

## 🕹️ 2. 右クリックで飛び出す「プロ仕様の3択メニュー」の使い方

以前あった『JwNavigator停止.exe』は、パレットの利便性を究極に高めるため、**右クリックメニューの中へと美しく引き算（統合）**されました。

パレットのグレーの背景部分をマウスで右クリックすると、以下の3択メニューが出現し、わざわざ別の停止アプリを探さなくても、その場の一撃で安全にコントロール・ファイルロックを解除できます。

*   **`🛠️ 設定 (Ver2.0予定)`**
    *   未来のD&Dボタン並び替え画面や、空きキーを自動で調べて合流させるコックピットへの美しい入り口（現在は安全な待機状態です）。
*   **`⚙️ このパレットだけを閉じる`**
    *   マルチタスク中、今見ているその図面用のパレットだけをフッと消滅（非表示）させます（裏で動いている他の図面用パレットや監視システムは元気に常駐継続します）。
*   **`❌ JwNaviシステムを終了する`**
    *   裏で動いている常時監視システムごとすべてを一撃で完全停止。Windowsのメモリから存在を完全に引き算し、即座にパレットのフォルダを移動したり、削除したりできるまっさらな状態へ戻します。

---

## 🎨 3. アイコンを自分の好きな画像(PNG)にするルール

本アプリは、画像と内蔵プログラムの自動両対応（ハイブリッド）構造になっています。
エクセル（`config/config.csv`）を書き換えてボタンを自由に増やしたり並び替えたりした際、自作のアイコンをドッキングさせるルールは以下の通りです。

### 📌 ルール：CSVの5列目（アイコン名）の文字と、ファイル名を100%完全一致させる

エクセルの5列目に書いたアルファベット文字列を基準に、システムがアイコンを探しに行きます。

#### 【パターンA】 自作のPNG画像（イラスト）をボタンにしたい場合
* `png_icons/` フォルダの中に、縦横 **44px × 44px**（最大48px）のPNG画像（透過対応の正方形）を用意します。
* ファイル名は、**CSVの5列目に書いたアルファベット名と「完全に同じ名前（すべて小文字）」** で保存してください。
  * 例：CSVの5列目が `range` ➔ 画像の保存名は **`png_icons/range.png`**

#### 【パターンB】 PythonのCanvas（数式描画コード）でアイコンを自作する場合
* `icons/` フォルダの中に、自作した描画コードのPythonファイル（`draw` 関数を内蔵したもの）を配置します。
* ファイル名は、**CSVの5列目に書いたアルファベット名と「完全に同じ名前」** で保存してください。
  * 例：CSVの5列目が `range` ➔ Pythonファイルの保存名は **`icons/range.py`**
* ※EXE化（パッケージ化）する際は、`main.py` の上部にあるインポート部分（隠し玉シールド）へ、新しく作った **`import icons.range`** の1行を忘れずに書き足してください。

#### 【パターンC】 画像もCanvasコードも用意しない場合（自動救済）
* 画像やコードを用意しなくても、システムが自動で救済します。
* CSVの3列目に書いた「コマンド名（例：複線）」の日本語を読み取って、**ボタンの真ん中に太字で「複線」とクッキリ自動描画**します。画像のないボタンは、内蔵されている最新の「極太高視認性Canvas図形」が自動で美しく描画されますので、すべての画像を用意する必要はありません。

*   **`JwNavigator.exe`**
    ダブルクリックすると静かに起動します。図面を開くと「自動追従（ピンク）」で真横に吸い付き、パレットをマウスで引きずって動かすと「自由配置（グレー）」にトグル変身します。
