# JwNavigator Ver3.76 取扱説明書

高解像度（4K等）モニター環境では、Jw_cad本体のツールバーが小さく、マウスで狙うのが負担になります。この負担を軽減するために開発された、Jw_cad専用のコマンドパレットです。

インストール不要。`JwNavigator.exe` を置いて実行するだけで使えます。

> **設定の保存場所について（更新前に一度お読みください）**
> 本体（exe一式）と、あなたの設定（ボタンの配置など）は**別の場所**にあります。
> * 本体 … 置いたフォルダ（例: `C:\jww\JwNavigator\`）
> * 設定 … `%APPDATA%\JwNavigator\`
>
> このため、**新しいバージョンが出たらフォルダごと上書きして構いません。設定は消えません。**
> 逆に、別のPCへ移す場合は、フォルダをコピーしただけでは設定は移りません（`%APPDATA%\JwNavigator\` も一緒にコピーしてください）。

## こんなことができます

* **押しやすい大きさのボタンを、好きな場所に。** よく使うコマンドだけを選んで並べられます。ボタンの大きさはパレットごとに指定でき、色とアイコンはボタンごとに変えられます。パレットは図面ウィンドウに自動で追従するので、画面をどう動かしても手元から離れません（追従をやめて好きな位置に固定することもできます）。

* **今どのコマンドを使っているかが、パレット側でも光ります。** Jw_cad本体の状態を見て、選択中のコマンドのボタンが凹みます。Jw_cad本体のツールバーから選んだ場合も連動します。

* **レイヤの表示状態に名前を付けて保存し、ワンクリックで戻せます。** 「電灯配線図」「空調図」のように、そのとき見たいレイヤの組み合わせを丸ごと記録できます。毎回レイヤをぽちぽち切り替える作業がなくなります。

* **線属性とレイヤをまとめて切り替える「モードボタン」。** 「補助線を引きたい」と思ったら1回押すだけで、線色・線種・書込レイヤ・水平垂直まで一度に切り替わります。別のコマンドに移ると**元の設定へ自動で戻る**ので、戻し忘れがありません。**「SXF対応拡張線色・線種」にも対応**しています（設定画面のチェックを入れると、16色・15線種の中から選べます）。図面側のSXFの状態は、モードボタンを抜けたときに元へ戻します。

* **よく一緒に使うコマンドは1つのボタンにまとめられます。** 「伸縮・面取・コーナー」のように似た仲間を1個にまとめ、押すと中身が開きます。省スペースになるうえ、探す時間も減ります。

* **アイコンは自分で用意したPNG画像に差し替えられます。** 現場で通じる見た目に変えてください。

* **設定はすべて画面上で完結します。** 設定ファイルを手で書く必要はありません（そのほうが早い人のために、直接編集する方法も残してあります）。

## うまく動かないときは

**`JwNavigator_Log.txt` を送ってください。** `JwNavigator.exe` と同じフォルダに自動で作られます。

このログには、動作の記録に加えて、起動時のJw_cad側の状態（外部変形の設定、キー割り付け、画面の拡大率、ツールバー構成など）が記録されています。**このファイルさえあれば、離れた場所のPCで起きた不具合でも原因を特定できることがほとんどです。**

「何をしたら、どうなったか」を一言添えてもらえると、さらに早く特定できます。

> 補足: レイヤ保存機能を使うため、Jw_cad側の環境設定ファイル（`Jw_win.jwf` 等）へ外部変形の呼び出しキーを1行だけ登録します。書き換える前に `.bak_jwnavigator` という名前でバックアップを作り、既に他の用途で使われている割り当ては**絶対に書き換えません**（空いているキーを自動で探します）。

## 1. おすすめの設置場所（超重要!!）

本アプリ一式（フォルダごと）をデスクトップ等で動かすと、Windowsの仕様で**OneDriveの自動同期がうるさく走り、動作が重くなったりファイルがロックされる原因**になります。

トラブルを完全に防ぐため、本アプリのフォルダは **`C:\jww\` フォルダの中（Jw_cad本体と同じ場所）に格納して動かすのが圧倒的におすすめ**です。
（例： `C:\jww\JwNavigator\` の中に`JwNavigator.exe`一式を並べる）

### 「WindowsによってPCが保護されました」と出た場合

署名付きの配布ではないため、`JwNavigator.exe`を実行するとWindows SmartScreenの警告が出ます（初回だけとは限りません）。表示された画面の**「詳細情報」**をクリックすると**「実行」**ボタンが出るので、それを押せば起動できます。

社内のグループポリシーで「実行」ボタン自体が表示されない設定になっている場合は、ユーザー側の操作だけでは回避できないため、IT部門に許可(除外設定)を依頼してください。

**注意**: 上の「詳細情報」→「実行」で起動できるのは、Windows 11の「Smart App Control」が**OFF**の場合だけです。**ONになっていると警告は出ますが、実行に進む手段がなくブロックされます**。設定→プライバシーとセキュリティ→Windowsセキュリティ→アプリとブラウザーの制御→Smart App Controlを確認してください（「評価モード」ならOFFにできますが、「オン」で固定済みの場合はWindowsの再インストールが必要です）。

## 2. 起動と基本操作

`JwNavigator.exe` をダブルクリックすると静かに起動し、画面には見えませんがタスクトレイ（画面右下の通知領域）にアイコンが常駐します。図面を開くと、その図面の左右にパレットが自動でくっつきます。

### パレットの「追従」と「自由配置」

パレット上部の `👣 追従` ボタンをクリックするか、パレット自体をドラッグして動かすと、`自由` 表示に切り替わります。

* **`👣 追従`（ピンク）**: Jw_cadのウィンドウに磁石のようにくっついて追いかけてくる状態。
* **`自由`（グレー）**: 好きな場所に固定できる状態。パレットを右クリックして「📌 終了時の配置を記憶する」にチェックを入れておくと、次回起動時も同じ場所に復元されます。

### タスクトレイアイコンからできること

トレイアイコンを右クリックすると、以下のメニューが出ます。

* **`⚙️ 編集`**: ボタンの追加・削除・並び替え・色/アイコン変更ができる設定画面を開きます（ダブルクリックでも同じ画面が開きます）。
* **`📌 終了時の配置を記憶する`**: 上述の「自由配置」の位置を、次回起動時にも復元するかのON/OFFです（トレイからも切り替えられます）。
* **`👁️ 隠したパレットを再表示`**: 後述の「このパレットだけを閉じる」で消したパレットを全部戻します。
* **`🔄 初期構成を選び直す`**: 初回起動時に選んだパレット構成の選択画面をもう一度呼び出し、今の配置を上書きします（「設定を色々いじって元に戻したい」時用。上書き前に確認が入ります）。
* **`❌ JwNaviシステムを終了する`**: 常駐監視も含めて完全に終了します。フォルダの移動・削除・上書きインストールをしたい時はここから終了してください。

パレット自体を右クリックしても、同じ設定/終了メニューに加えて「このパレットだけを閉じる」（そのJw_cadウィンドウ分だけ非表示にする）が出ます。

## 3. パレットの右クリックメニューを簡略化する

パレット右クリックメニューの項目を絞りたい場合は `⚙️ 編集` の「右クリック」タブから、項目ごとに表示ON/OFFを切り替えられます。`⚙️ 編集` 自体は誤って消せないよう常に表示されます。

タスクトレイアイコンの右クリックメニューはこの設定の影響を受けず、常に全項目が表示されます（管理者・開発側がいつでも全機能へアクセスできるようにするためです）。

## 4. グループボタンについて

似た仲間のコマンド（例：伸縮・面取・コーナー）をまとめて1個のボタンに収納できる「グループボタン」です。右下に小さい青い三角のバッジが付いているボタンがこれです。

* **使い方**: グループボタンを押すと、中身の一覧がポップアップで出ます。使いたいものをクリックするとそのコマンドが実行され、ポップアップは閉じます（外側クリックや`Esc`キーでも閉じます）。
* 中身のコマンドを選ぶと、グループボタン自体の見た目もそのコマンドの見た目に一時的に切り替わり、選択中は凹んで表示されます。別のコマンドに切り替えると、グループ自体の見た目に自動で戻ります。
* **作り方**: `⚙️ 編集` → 右側の「追加」ボタン → 一覧の先頭にある「➕ グループボタン」を選ぶ → 名前を入力（例：「作図系」）→ 保存。作ったグループを選ぶと詳細欄に「中身を編集…」ボタンが出るので、そこからコマンドの追加・削除・並び替え・アイコン/色の個別設定ができます。不要になったら詳細欄の「グループ解除」で、中身を個別ボタンへ展開して元に戻せます。
* グループの中身には、通常のコマンドだけでなく「モードボタン」も入れられます（コマンド・線属性・レイヤーを一括で切り替えるボタン。作成は中身編集画面の「追加」から同様に選べます）。

複数コマンドを自動で連続実行する「マクロ」ボタンも構想中ですが、今回はまだ収録していません（また今度）。

## 5. レイヤ保存ボタンについて

「電灯配線図」「配管図」のように、全レイヤグループ・全レイヤ（16×16＝256マス）の表示/非表示・編集可否の状態をまとめて記録し、あとからワンクリックで呼び戻せるボタンです。

* **作り方**: `⚙️ 編集` → 右側の「追加」ボタン → 一覧の「➕ レイヤ保存(全自動)」を選ぶ。これで保存ボタンが1個だけ作られます（名前入力はここでは不要です）。
* **保存の使い方**: 保存ボタンを押すと、名前を聞かれます（例：「電灯配線図」）。OKを押すと、選択操作も含めて全部自動で進み、**5〜10秒程度**で完了します。新しい名前なら、その名前の**復元ボタンが保存ボタンのすぐ後ろに自動で追加**されます。すでに使った名前を入力すると、上書き確認のうえ保存し直せます。処理中はボタンが凹んだ見た目になるほか、画面上部に「レイヤ情報保存中… 触らないでください」というバナーが出ます。
* **復元の使い方**: 自動で追加された「電灯配線図」のようなボタンを押すと、記録した状態を即座に反映します。
* **保存ボタンは1個のまま、復元ボタンだけがどんどん増えていく**設計です。「電灯配線図」「配管図」のように何個でも別々に保存できます。**復元ボタンが増えていく分、保存ボタンの後ろのスペースは空けておいてください。**
* 復元すると書込レイヤ（今編集中のレイヤ）も保存時点のものに切り替わりますが、直後に元の書込レイヤへ自動で戻すようにしているため、作業中のレイヤが変わってしまうことはありません。

### ⚠️ 使う前に1つだけ確認してください（`Jw_win.jwf`）

レイヤ保存は、Jw_cadの「外部変形」をキー操作で呼び出して実現しています。この**キーの割り付けはJwNavigatorが自動で登録します**が、Jw_cadはこの設定を **`Jw_win.jwf` というファイルからしか読み込みません**。

このファイルは、Jw_cad側で一度も「環境設定ファイルの書込み」をしたことがないPCには**存在しません**。その場合、いくら登録しても読み込まれないため、レイヤ保存は動きません（ボタンを押しても失敗します）。

該当する場合は起動時にお知らせが出ます。次の手順で1回だけ作ってください。

1. Jw_cadで `[設定]` → `[環境設定ファイル]` → `[書込み]` を選ぶ
2. Jw_cadのフォルダ（通常 `C:\jww`）に **`Jw_win.jwf`** という名前で保存する
3. Jw_cadを再起動する

現在の設定がそのまま保存されるだけなので、設定が変わってしまうことはありません。一度作れば、以降はずっと有効です。

### その他の注意点

* 保存には「編集可能なレイヤが少なくとも1つある」ことが必要です。編集可能なレイヤが1つも無い状態で保存を押すと失敗します（ボタンは自動で元の見た目に戻ります）。
* 全自動版は、選択対象を用意するために書込レイヤへ目印の点を1個作図してから自動で消す、という処理を裏側で行っています。何らかの理由で消去に失敗すると**点が図面に残る可能性**があります（見つけたら手動で削除してください）。また、この作図・消去は「元に戻す(アンドゥ)」の履歴にも積まれます。
* 保存中は、マウスカーソルが自動で動きます。**処理が終わるまでマウス・キーボードを触らないでください。**

### 旧方式のボタン（通常は使いません）

「追加」の一覧で **「テスト版も表示」** にチェックを入れると、次の2つも選べます。全自動版がうまく動かない環境での切り分け用です。

* **🧪 レイヤ保存(要選択・テスト用)**: 押す**前に、図面上で何か図形を1つ以上、自分で選択しておく**必要があります。目印の点を作図しないため、アンドゥ履歴を汚したくない場合に使えます。
* **🧪 レイヤ保存(通常版・テスト用)**: 最も古い方式で、**10〜20秒程度**かかります。確実性を優先した予備です。

どちらも、復元ボタンの自動追加や名前の付け方は全自動版と同じです。

## 6. アイコンを自分の好きな画像(PNG)にするルール

本アプリは、画像と内蔵プログラムの自動両対応（ハイブリッド）構造になっています。設定画面（`⚙️ 編集`）のアイコン選択で、サムネイル一覧から選ぶのが基本の使い方です。自作の画像を追加したい場合のルールは以下の通りです。

#### 【パターンA】 自作のPNG画像（イラスト）をボタンにしたい場合
* `png_icons/` フォルダの中に、正方形（44〜48px、透過対応）のPNG画像を好きなファイル名で置きます（例: `myicon.png`）。
* 保存すると、そのファイル名がそのままアイコン名として設定画面のアイコン選択サムネイル一覧に自動で追加されるので、あとは画面を見て選ぶだけです。名前を何かに合わせる必要はありません。
* 例外として、「このコマンドをパレットに新しく追加した瞬間、自動でこのアイコンを付けたい」場合だけ、`data/commands_master.csv`の該当行の`default_icon`列と同じファイル名にしておくと、追加時に手動で選ばなくても自動で付きます。

#### 【パターンB】 PythonのCanvas（数式描画コード）でアイコンを自作する場合
* `icons/` フォルダの中に、`draw(canvas, x, y)` 関数を持つPythonファイルを好きなファイル名で配置します（例: `myicon.py`）。
* こちらも同様にファイル名がそのままアイコン名になり、画面のサムネイル一覧から選べます。exe化されたバージョンでも自動的に同梱・認識されるので、追加のimport作業などは不要です。

#### 【パターンC】 画像もCanvasコードも用意しない場合（自動救済）
* 画像やコードを用意しなくても、システムが自動で救済します。ボタンの真ん中にコマンド名を太字で自動描画します。

## 7. config.jsonを直接編集したい人向け

パレットの設定は`config.json`というテキストファイルに保存されています。保存場所は`%APPDATA%\JwNavigator\config\config.json`です(エクスプローラーのアドレス欄に`%APPDATA%\JwNavigator`と入力すると開けます)。exeを入れ替えたり別のフォルダへ移動したりしても、この設定は消えません。設定画面から作れない組み合わせを試したい時などは、メモ帳等で直接編集することもできます。

* 保存する時は文字コードを**UTF-8**にしてください（Windows 11の新しいメモ帳ならデフォルトで大丈夫です。古いメモ帳だとANSIになり日本語が壊れることがあります）。
* JSONの構文（カンマや括弧）を崩すと、その面（左右どちらか）のボタンが読み込めず空になります。ただしアプリ自体がクラッシュすることはありません（壊れていたら黙って空の状態にフォールバックする作りになっています）。
* **編集する時は`⚙️ 編集`の設定画面を閉じておいてください。** 開いたまま直接編集して、そのあと設定画面側で「保存」を押すと、直接編集した内容が上書きされて消えます。編集後はアプリを再起動するか、トレイ経由で設定画面を開き直すと反映されます。

## 8. 不具合報告・利用状況のログについて

* `JwNavigator_Log.txt`（exeと同じフォルダに自動生成）に、動作ログが記録されます。不具合が起きた時はこのファイルの中身をコピペして報告してもらえると原因調査が早いです（肥大化を防ぐため5MBを超えると自動的に前半を切り詰めます）。
* 「JwNavigatorを使っていない人にも、jw_cadの使用状況だけ調べてほしい」という場合は、同梱の `JwNavigator_UsageLogger.exe`（`dist/JwNavigator_UsageLogger/` フォルダ）を単体で配れます。起動して作業してもらい、Ctrl+Cで終了すると集計結果が出ます。座標やキーの内容などは一切記録しません。

### 開発者の方へ

このアプリは、**プログラミング初心者が Claude Code と一緒に作ったもの**です。コードの書き方が最適とは限りません。

ただ、**Jw_cadを外から自動操作するための調べ物には、それなりの時間をかけています。** 実機で試して分かったことは、なるべく「なぜそうしたか」「何を試して駄目だったか」まで含めて残すようにしました。どこにも書かれていないことが多く、同じ所で詰まる人がいると思います。

* [`DECISIONS.md`](DECISIONS.md) … 設計判断と、誤診して後から訂正した記録
* [`doc/HANDOFF_layer_control.md`](doc/HANDOFF_layer_control.md) … レイヤ制御・外部変形まわりの調査ログ
* [`doc/シート管理_設計メモ.md`](doc/シート管理_設計メモ.md) … 仕様書(`JWW_SMPL.BAT`等)の読み解きを含む設計メモ
* [`config/keybind_setup.md`](config/keybind_setup.md) … 外部変形のキー割り付け
* ソース中の `👑` で始まるコメント … 実機で確認した挙動と、その根拠

例えば次のようなことが書いてあります。

* 外部変形を、ファイル選択ダイアログを経由せずキー一発で無人起動する方法
* その設定(`GCOM_1XX`)は**レジストリに保存されず、`Jw_win.jwf` からしか読まれない**こと（設定の大半はレジストリ側にあります）
* レイヤバーとレイヤグループバーを、配置や表示名に依存せず見分ける方法
