# JwNavigator コマンドマスター 説明書

## 1. 目的

このファイルは、Jw_cad のコマンド情報を整理し、JwNavigator のボタン構成および状態収集システムで共通利用するためのマスターCSV `commands_master.csv` の説明書です。

対象は、Jw_cad のツールバー設定で確認した **1～78番の78項目**です。

> 注意：以前の「79コマンド」という表現は誤りで、対象は78項目です。

---

## 2. 基本方針

このマスターでは、Jw_cad上で同じコマンドを指していても、出典によって名称や番号が異なるため、それぞれを分離して記録します。

### 3種類の情報

| 情報 | CSV項目 | 意味 |
|---|---|---|
| ツールバー情報 | `toolbar_no` / `toolbar_name` | Jw_cadのツールバー設定での番号・表示名 |
| ショートカット情報 | `shortcut_no` / `shortcut_name` | Jw_cadのショートカット登録可能コマンド一覧での番号・名称 |
| 正式名称・カテゴリ | `official_name` / `category` | 今回確認したカテゴリ分け資料での正式名称・カテゴリ |

### 例：建断

| 項目 | 内容 |
|---|---|
| toolbar_name | 建断 |
| shortcut_name | 断面 |
| official_name | 建築断面 |
| category | 作図 |

つまり、3つの名称は別々に保存し、同じコマンドとして1つの `command_id` に統合します。

---

## 3. CSVの各項目

| 列名 | 内容 |
|---|---|
| `command_id` | JwNavigator内部で管理するコマンド識別子。C001～C078 |
| `toolbar_no` | Jw_cadツールバー設定番号 |
| `toolbar_name` | ツールバー上の表示名 |
| `shortcut_no` | ショートカット登録可能コマンドの番号 |
| `shortcut_name` | ショートカット登録画面での名称 |
| `official_name` | 正式名称として採用する名称 |
| `category` | 作図・編集・設定・その他 |
| `shortcut_key` | カテゴリ資料で確認したショートカットキー |
| `shortcut_available` | ショートカット情報が確認できているか |
| `collect_target` | 状態収集の対象か |
| `verified` | 現時点で名称等の確認が済んでいるか |
| `status_pattern_count` | 収集した状態パターン数。現時点では0 |
| `collector_finished` | 状態収集完了フラグ |
| `collector_checked` | 収集結果の確認完了フラグ |
| `state_pattern_created` | `state_patterns.py` 用データ作成済みか |
| `button_created` | JwNavigator側のボタン作成済みか |
| `remarks` | 補足欄。原則として推測情報を入れない |

## 4. 現時点で確定していること

### ツールバー

- 対象：1～78
- 合計：78項目
- ツールバー番号は `toolbar_no`
- 表示名は `toolbar_name`

### カテゴリ

以下の4分類を使用します。

- 作図
- 編集
- 設定
- その他

カテゴリは、今回提示された「カテゴリ分け＆正式名称」の資料を基準とします。

### 正式名称

正式名称は、今回提示されたカテゴリ別リストの名称を採用します。

推測による正式名称への変更は行いません。

### ショートカット

ショートカット登録可能コマンドについては、別途提示された番号付きリストを基準とします。

番号には欠番がありますが、これは異常ではなく、**存在する番号だけを記録します。**

欠番を推測して補完しません。

## 5. 名称の扱い

同じコマンドでも、Jw_cadの画面によって名称が異なる場合があります。

例：

| ツールバー | ショートカット | 正式名称 |
|---|---|---|
| 建平 | 建具平面 | 建築平面 |
| 建断 | 断面 | 建築断面 |
| 建立 | 立面 | 建築立面 |
| 複写 | 複写 | 図形複写 |
| 移動 | 移動 | 図形移動 |
| 属変 | 属性変更 | 属性変更 |
| 外変 | 外部 | 外部変形 |
| 選択図 | 登録選択図 | 登録選択図形 |
| 図登録 | 図形登録 | 図形登録 |
| 線記変 | 記号 | 線記号変形 |
| パラメ | ﾊﾟﾗﾒﾄﾘｯｸ | パラメトリック変形 |

これらを別コマンドとして重複登録せず、`command_id` で同一コマンドとして管理します。

## 6. 状態収集について

このCSVは、今後の状態収集システムの基礎データとして使用します。

各コマンドについて、原則として以下を収集します。

1. コマンド実行前
2. マウスオン
3. クリック直後
4. 作業領域へカーソル移動
5. 1クリック後
6. 2クリック後（必要なコマンドのみ）
7. 右クリック後（存在する場合）
8. ESC後
9. コマンド終了時
10. その他の状態変化

ドラッグ操作は今回の収集対象から除外します。

---

## 7. 実測データの原則

状態収集データについては、推測で埋めません。

以下を明確に区別します。

- **実測**：実際にJw_cadを操作して確認
- **ログ確認**：取得ログから確認
- **未確認**：まだ確認していない
- **推測**：原則としてマスターには採用しない

特に `state_pattern_count` や `state_pattern_created` などは、実際の収集作業が完了するまで変更しません。

## 9. 重要な注意事項

### 勝手に補完しない

番号・名称・カテゴリ・ショートカット・状態遷移のいずれについても、資料から確認できない情報を推測で確定しません。

### JwNavigator本体と分離する

状態収集のためだけにJwNavigator本体を大きく変更しません。

収集専用ツールを優先します。

### マスターと収集結果を混在させない

`commands_master.csv` は「コマンドの基本情報」を管理するマスターです。

実際の状態遷移データは別CSV等に保存し、必要に応じて `command_id` で紐付けます。
